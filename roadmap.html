Planned
#
MCP Support
Two directions: (1) Nexus consumes MCP servers as tools available to the LLM during chat — the user points Nexus at an MCP endpoint and those tools appear alongside web_search / fetch_url. (2) Nexus exposes itself as an MCP server so Claude Code and other MCP clients can route requests through Nexus as a model provider.
Brainstorm needed Backend Frontend
#
Ollama Backend Abort
Investigate stopping Ollama generation server-side when the client disconnects. TCP disconnect does not propagate through Docker networking to the llama runner — same known limitation as Open WebUI. UI stop already works; only the backend continues generating after cancellation.
Known limitation Backend
#
Dockerfile Non-Root User
Run the container as a non-root user via a PUID/PGID entrypoint pattern. Currently blocked because Unraid host volumes are root-owned and a simple USER nexus instruction breaks volume writes on first run. Requires an entrypoint script that chowns the data directory before dropping privileges.
Blocked — Unraid compat Docker
#
ENCRYPTION_SECRET Migration
ENCRYPTION_SECRET is currently derived from ADMIN_API_KEY when not explicitly set. Decoupling them requires a documented migration path for existing installs — re-encrypting stored config and conversations without data loss during the transition.
Migration risk Backend Security

v1.2.0 — dev branch
✓
URL Fetch Tool
fetch_url LLM tool added alongside web_search. Fetches a URL server-side, strips HTML to plain text (scripts, styles, comments removed; entities decoded; block tags → newlines), returns up to 50 KB to the model. Gated by the existing SearXNG globe toggle — no new UI required. Tool-calling path refactored from a single-call branch to a multi-turn agentic loop (up to 4 tool calls per turn): model can chain web_search → fetch_url on a result → answer. Both Ollama-native and OpenAI-compat message shapes handled. SSRF-protected (cloud metadata blocked; LAN allowed). 15-second per-fetch timeout. New standalone module fetchUrl.ts with 26 unit tests.
